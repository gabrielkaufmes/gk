Variable mapping

Assign each wireframe variable to a column from your Aluplast or WHNet query. Auto-mapped values (when names match) show an auto badge — overrides save automatically.

Run the queries first. Switch to the Aluplast query and WHNet query tabs, click Run preview on each. That populates the source columns this screen draws from.

Status mapping

The 8 flow positions are fixed. For each you can edit the label, pick the single SQL value that lands in it, and pick a band color. Materials display is hardcoded by position: flow #1 and #2 show nothing, #3–#8 show letters + dates side by side.
